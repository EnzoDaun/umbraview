stars.bin: star positions, magnitudes and color indices

stars.bin is derived from the HYG star database, version 4.4, by David Nash (astronexus).

Source:  https://codeberg.org/astronexus/hyg
         file data/hyg/CURRENT/hyg_v44.csv.gz
License: Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0)
         https://creativecommons.org/licenses/by-sa/4.0/

Changes made to the original:

- Kept only the stars with apparent visual magnitude up to 6.5 and removed the entry for the
  Sun (the first row of the catalog).
- Kept only four columns: right ascension (ra), declination (dec), apparent magnitude (mag) and
  B-V color index (ci). Right ascension and declination were converted to a unit vector in the
  J2000 equatorial frame (x = cos(dec) cos(ra), y = cos(dec) sin(ra), z = sin(dec)).
- Sorted the stars from brightest to faintest.
- Changed the format from gzipped CSV to a binary file: five little-endian 32-bit floats per
  star (x, y, z, magnitude, B-V). A star with no color index in the catalog has NaN in the
  B-V field.

The file is generated by scripts/prepare-data/prepare_stars.py in the UmbraView repository
(https://github.com/EnzoDaun/umbraview).
